# Flat Management App v7 - HTML Prototype

A complete mobile-first HTML prototype for a rental property management platform featuring a friendly, approachable design and self-service booking system.

## 🏠 Project Overview

This prototype demonstrates a comprehensive rental property management platform with both guest-facing and admin interfaces. The design emphasizes accessibility, mobile-first responsive design, and a warm, welcoming user experience.

## ✨ Features

### Guest Interface
- **Property Listing**: Browse 6 unique rental properties with detailed information
- **Property Details**: View comprehensive property information, amenities, and availability
- **Booking System**: Complete booking form with guest information and special requests
- **Responsive Design**: Optimized for mobile, tablet, and desktop devices

### Admin Interface
- **Secure Login**: Mock authentication system for property managers
- **Dashboard Overview**: Quick stats and performance metrics
- **Property Management**: View and manage all rental properties
- **Booking Management**: Track current and upcoming reservations

## 🎨 Design System

### Color Palette
- **Primary**: Emerald (emerald-600, emerald-700)
- **Secondary**: Soft blues, greens, and warm earth tones
- **Background**: Slate-50 for main background, white for content cards
- **Text**: Gray-800 for headings, Gray-600 for body text

### Typography
- **Font Family**: Inter (Google Fonts)
- **Responsive**: Mobile-first approach with adaptive sizing

### Components
- **Cards**: Rounded corners (rounded-xl), subtle shadows
- **Buttons**: Emerald primary, hover states, generous padding
- **Forms**: Clear labels, focus states, validation styling
- **Navigation**: Consistent back buttons and breadcrumbs

## 🛠 Technical Implementation

### Framework & Tools
- **HTML5**: Semantic markup structure
- **Tailwind CSS**: Utility-first CSS framework via CDN
- **Google Fonts**: Inter font family
- **Responsive Design**: Mobile-first approach using Tailwind breakpoints

### Key Technical Features
- **Mobile-First**: All layouts designed for mobile and scaled up
- **Semantic HTML**: Proper heading hierarchy and accessibility considerations
- **Placeholder Images**: Consistent placeholder.co images with appropriate sizing
- **No JavaScript Dependencies**: Pure HTML/CSS prototype
- **Cross-Browser**: Compatible with modern browsers

## 🚀 Getting Started

1. **View the Prototype**: Open `index.html` in any modern web browser
2. **Navigate the Site**: 
   - Browse properties on the home page
   - Click "View Details" to see property information
   - Use "Book Now" to access the booking form
   - Try "Admin Login" to access the management interface
3. **Test Responsiveness**: Resize browser window or use device emulation
