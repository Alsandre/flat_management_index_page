# StayEase - Rental Property Management Platform

A modern, responsive rental property management platform built with clean HTML/CSS and a component-based architecture.

## 🏠 Project Overview

StayEase is a 6-property rental platform designed with a mobile-first approach, featuring property listings, detailed views, booking functionality, and an admin dashboard for property management.

## ✨ Features

- **Property Listings**: Hero section with search functionality and responsive property grid
- **Property Details**: Image galleries, amenities, and integrated booking sidebar
- **Booking System**: Complete guest information forms with booking summaries
- **Admin Dashboard**: Statistics overview and calendar management with color-coded availability
- **Responsive Design**: Mobile-first layout optimized for all devices (320px+)

## 🎨 Design Principles

- Clean, modern, minimalist aesthetic
- Personal and trustworthy feel (not corporate)
- Mobile-first responsive design
- Touch-friendly interface (44px+ buttons)
- Professional color scheme (whites, grays, blue accent)

1. Open `index.html` in any modern web browser

4. Review the complete user flow from property search to booking

## 📱 Browser Compatibility

- Modern browsers (Chrome, Firefox, Safari, Edge)
- Mobile browsers (iOS Safari, Chrome Mobile)
- Responsive breakpoints: 768px (tablet), 1024px (desktop)

## 🏗️ Architecture

- **Single HTML File**: Complete prototype in one file for easy deployment
- **Component-Based CSS**: Modular styles organized by functionality
- **Mobile-First**: CSS written with mobile devices as the primary target
- **Semantic HTML**: Proper structure for accessibility and SEO
